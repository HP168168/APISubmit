# 百度链接 API 自动提取与批量推送系统

基于 Python 开发的现代化可视化执行程序，严格契合百度搜索资源平台官方《如何使用API推送功能》规范，专为站长与 SEO 运营团队打造。

---

## ✨ 核心特性

1. **整站多层深度智能抓取引擎 (Crawler)**：
   - 支持指定起始 URL（首页或栏目页），自动沿站内链接层层深入遍历；
   - 支持设置爬取深度（1~5 层）与最大抓取网页限制（50~2000 页），支持随时暂停或停止；
   - 自动解析 `<title>` 页面标题与绝对化 URL，严格限制同主域，自动过滤图片、音视频、JS/CSS、压缩包等非网页资源。

2. **本地持久化与防重复推送机制（SQLite）**：
   - 抓取出的所有链接自动进入本地轻量 SQLite 数据库（`data/push_tool.db`）；
   - 记录每一条链接的**提交状态（待推送 / 成功 / 失败 / 忽略）**、历史推送次数、最后提交时间、响应详情；
   - 提供**【仅勾选待推送链接（防重复）】**一键快捷筛选，避免因重复提交旧链接而被百度系统降额扣罚。

3. **批量推送与百度接口规范对接**：
   - 采用标准 `POST http://data.zz.baidu.com/urls?site={site}&token={token}` 接口与 `text/plain` 纯文本流传输；
   - 自动按批次切分（单次推送 <= 500~2000 条）；
   - 实时解析百度返回的 `remain`（当日剩余可用额度）、`success`（成功新增条数）、`not_same_site` 及各类错误码（`400 site error`, `401 token invalid`, `over quota` 等）。

4. **多站点集中管理与配置切换**：
   - 支持同时维护多个网站的域名（site）与 16 位准入密钥（token），可快速切换不同站点工作区。

5. **现代高颜值 Web 交互面板**：
   - 采用控制台仪表盘风格，支持状态徽章、筛选过滤、关键词检索、手动批量粘贴链接、导出 CSV/TXT。

## 🚀 启动与使用指南

### 方式一：Windows 一键双击启动（最简便）
直接双击项目根目录下的 **`start.bat`** 脚本即可，系统将自动启动后台服务并在您的默认浏览器打开控制台：
👉 访问地址：`http://127.0.0.1:5000`

### 方式二：命令行手动启动
```bash
# 安装必要依赖（若未安装）
pip install -r requirements.txt

# 启动程序
python app.py
```

## 📖 操作流程示意

1. **第一步：添加或选择站点**
   - 点击右上角【站点管理】，填写站点名称（如 `我的官网`）、站长平台绑定的域名 `site`（如 `www.example.com`）及 16 位 `token`，点击保存。
2. **第二步：遍历抓取站内链接**
   - 点击【填入站点首页】，选择遍历深度（默认 2 层）和最大网页数，点击【开始智能遍历】。
   - 进度条将实时显示访问页数与发现链接数，抓取完毕后表格自动刷新。
3. **第三步：智能勾选与防重复**
   - 点击【仅勾选待推送链接 (防重复)】按钮，系统将自动高亮并勾选所有未推送过的新链接，自动排除已推送成功的旧链接。
4. **第四步：批量推送到百度**
   - 点击绿色的【立即推送勾选链接到百度】按钮，系统将自动分包提交，并在弹窗中直观展示本次成功条数、余量统计与批次日志。
